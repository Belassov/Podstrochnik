# История изменений

## 1.1.0 — 17 октября 2026

* окно всегда выходит на передний план по хоткеям `Ctrl+C+C` и `Ctrl+Alt+S` — даже если было
  открыто позади других окон;
* после перемещения окна по краям больше не появляется светлая линия;
* развёрнутое окно не накрывает панель задач;
* автозапуск: при входе в Windows окно не показывается, приложение остаётся в трее и открывается
  по вызову; `Esc` сворачивает окно в трей;
* интерфейс стал компактнее: убраны три кнопки («Перевести этот текст», «Перевести из буфера»,
  «Скопировать» — всё делается хоткеями и `Enter`), лишние подписи и пояснения; копирование
  перевода — маленькая кнопка в шапке карточки; убрана скрепка «Вставить из буфера» в чате;
* в шапке карточки перевода показывается язык исходного текста: «английский → русский»;
* размер окна по умолчанию 660×860, минимум 560×640, вёрстка подстраивается под высоту окна;
* скриншот для перевода сжимается до 1568 px — быстрее и дешевле;
* лог не обнуляется при запуске (прошлый запуск остаётся в `log.prev.txt`), текст переводов
  и чата в лог не пишется;
* репозиторий снова собирается: добавлены иконки и шрифты, которых не хватало.

## 1.0.0 — 17 октября 2026

Переписан на C#/.NET 8 + WebView2: интерфейс — HTML/CSS по макету (тёмная тема Catppuccin Mocha,
карточки, кнопки-пилюли, свой заголовок окна), логика нативная.

* перевод выделенного (двойной Ctrl+C), перевод с экрана (Ctrl+Alt+S с выделением области),
  перевод набранного текста и из буфера;
* чат с ответом на языке собеседника и русской подстрочкой, с автоматическим повтором,
  если модель ответила не на том языке;
* контекст сессии: лимит 50 000 токенов, счётчик заполнения, сброс;
* трей, автозапуск, Esc и крестик — в трей, полный выход через «Выход»;
* окно можно менять по размеру, вёрстка подстраивается;
* шрифты интерфейса (Inter, JetBrains Mono) вшиты в приложение — интерфейсу интернет не нужен.

### Прежняя линия

0.1–0.10 — версия на C/Win32: те же функции, светлое оформление, окно 900x656.
