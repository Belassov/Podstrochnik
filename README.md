# Подстрочник

Перевод выделенного текста на ходу: выделил текст в любой программе — получил перевод.
В том же окне чат, чтобы ответить собеседнику на его языке, а не переключать всё вручную.

[English version →](README.en.md)

## Пошаговая инструкция (для чайников)

Если ты такое никогда не ставил — просто иди по пунктам.

**Шаг 1. Скачай программу.** Открой [последний релиз](../../releases/latest) и в блоке
«Assets» скачай `Podstrochnik.exe`. Сохрани куда угодно — это один файл, установщика нет,
в систему программа ничего не прописывает.

**Шаг 2. Получи ключ OpenRouter.** Программа переводит через сервис OpenRouter.

1. Открой [openrouter.ai](https://openrouter.ai) и войди (Sign in — можно через Google
   или GitHub).
2. Перейди на [openrouter.ai/keys](https://openrouter.ai/keys) → **Create Key** → назови
   как угодно → **Create**.
3. Скопируй ключ: он начинается с `sk-or-`. Показывается он один раз, поэтому сразу
   сохрани его в блокнот.
4. Пополни баланс на 5–10 долларов (раздел **Credits**). Один перевод стоит примерно
   `$0,00002–0,00013`, то есть этих денег хватит на десятки тысяч переводов.

**Шаг 3. Впиши ключ в программу.** Самый простой способ:

1. Открой папку, куда скачал `Podstrochnik.exe`.
2. В проводнике щёлкни по адресной строке (там, где путь к папке), сотри путь, напиши
   `cmd` и нажми Enter — откроется чёрное окно сразу в этой папке.
3. Напиши `Podstrochnik.exe --setkey sk-or-сюда-свой-ключ` и нажми Enter.
4. Ключ сохранится в настройки, зашифрованный для твоей учётной записи Windows.

Не хочешь командную строку — можно руками: Win+R → вставь `%APPDATA%\Podstrochnik` → Enter →
открой `config.ini` блокнотом → в строке `api_key=` допиши ключ после знака равно → сохрани.
(В этом случае ключ лежит в файле открытым текстом.)

**Шаг 4. Запусти.** Двойной щёлчок по `Podstrochnik.exe`. Windows может предупредить,
что «издателя не удалось проверить» — нажми «Подробнее» → «Выполнить в любом случае»:
так бывает у небольших программ без платной подписи. Откроется окно, а рядом с часами
появится значок программы.

**Шаг 5. Пользуйся.**

* Выдели текст в любой программе и **дважды быстро** нажми `Ctrl+C` — откроется окно
  с переводом. Первое нажатие копирует как обычно, привычное копирование не ломается.
* `Ctrl+Alt+S` — перевод с экрана: экран замирает, обведи мышью область с текстом.
  Так переводятся надписи, которые нельзя выделить (игры, картинки, PDF).
* Поле внизу — чат: пишешь по-русски, ответ приходит на языке собеседника, ниже он же
  по-русски, чтобы видеть, что именно отправляешь.
* `Esc`, крестик и сворачивание прячут окно в трей. Полный выход — правый клик по значку
  в трее → «Выход».

**Если что-то не работает**

* «Нет ключа OpenRouter» — не сделан Шаг 3.
* Окно вообще не открылось — нет компонента WebView2 (в Windows 10/11 он обычно уже есть).
  Поставь «WebView2 Runtime» с сайта Microsoft и запусти снова.
* «Ошибка: HTTP 401» — ключ введён с ошибкой или уже удалён.
* «Ошибка: HTTP 402», «insufficient credits» — закончились деньги на OpenRouter.
* Что-то другое — открой `%APPDATA%\Podstrochnik\log.txt` (Win+R → вставить этот путь),
  последние строки обычно объясняют причину.

## Что умеет

* **Перевод выделенного текста** — два быстрых `Ctrl+C` в любой программе.
* **Перевод с экрана** — `Ctrl+Alt+S` с выделением области; текст с картинки распознаёт
  сама модель, отдельного OCR нет.
* **Перевод набранного текста и из буфера** — кнопки в окне, `Enter` в поле ввода.
* **Чат** — ответ на языке собеседника и он же по-русски ниже. Язык берётся из последнего
  переведённого текста; если модель ответила целиком по-русски, запрос повторяется.
* **Контекст сессии** — каждое новое выделение добавляется к контексту, поэтому имена
  и термины переводятся одинаково. Лимит 50 000 токенов, счётчик и кнопка сброса.
* **Окно** — размер меняется за любой край, вёрстка подстраивается.
* **Трей, автозапуск**, тёмная тема.

## Требования

Windows 10 или 11, компонент WebView2 Runtime (в системе есть вместе с Edge) и ключ
[OpenRouter](https://openrouter.ai/keys).

## Настройки и лог

* `%APPDATA%\Podstrochnik\config.ini` — ключ, модель, лимит контекста.
* `%APPDATA%\Podstrochnik\log.txt` — запуск, запросы, ошибки.
* Ничего, кроме текста, который ты переводишь, никуда не отправляется: настройки и лог
  лежат только на твоём компьютере.

## Модель

По умолчанию `deepseek/deepseek-v4.1-flash` через OpenRouter, без reasoning: быстро и дёшево,
картинки читает сама модель.

## Сборка

Нужен .NET SDK 8 (официальный от Microsoft) и команда:

```
dotnet publish -c Release -r win-x64
```

Интерфейс лежит в `ui/` и вшивается в exe; его можно посмотреть без сборки, открыв
`ui/preview.html` в браузере. Ключ в сборку вшивается файлом `EmbeddedKey.g.cs`
(шаблон — `EmbeddedKey.cs`); сборки с вшитым ключом не публикуются.
