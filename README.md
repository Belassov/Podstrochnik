# Подстрочник

Перевод выделенного текста на ходу: выделил текст в любой программе — получил перевод.
В том же окне чат, чтобы ответить собеседнику на его языке, а не переключать всё вручную.

[English version →](README.en.md)

![Подстрочник](screenshot.png)

## Что умеет

* **Перевод выделенного текста** — два быстрых Ctrl+C в любой программе. Первое нажатие
  копирует как обычно: обычное копирование не подменяется.
* **Перевод с экрана** — Ctrl+Alt+S: экран замерзает, тянешь рамку по нужной области,
  текст распознаётся и переводится. Работает там, где текст нельзя выделить: игры,
  картинки, PDF, чужие скриншоты.
* **Перевод набранного текста и из буфера** — кнопки в окне, Enter в поле ввода.
* **Чат** — пишешь по-русски, получаешь готовый ответ на языке собеседника и ниже он же
  по-русски, чтобы видеть, что именно отправляешь. Язык собеседника определяется по
  последнему переведённому тексту; если модель ответила целиком по-русски, запрос
  автоматически повторяется.
* **Контекст сессии** — каждое новое выделение добавляется к контексту, поэтому перевод
  держит имена и термины. Лимит 50 000 токенов, счётчик заполнения и кнопка сброса.
* **Окно** — размер можно менять за любой край, вёрстка подстраивается; Esc, крестик
  и сворачивание прячут окно в трей, полный выход — только через «Выход».
* **Автозапуск с Windows**, язык интерфейса RU/EN, тёмная тема.

## Требования

Windows 10 или 11, компонент WebView2 Runtime (в системе есть вместе с Edge) и ключ
[OpenRouter](https://openrouter.ai/keys).

## Установка и ключ

1. Взять `Podstrochnik.exe` из сборки.
2. Задать ключ один раз: `Podstrochnik.exe --setkey <ключ>` — он сохранится в `config.ini`
   зашифрованным через DPAPI. Можно и просто вписать в `config.ini` вручную.
3. Запустить: приложение появится в трее.

## Настройки и лог

* `%APPDATA%\Podstrochnik\config.ini` — ключ, модель, лимит контекста, шрифты интерфейса
  (`ui_font`, `chat_font`), положение окна.
* `%APPDATA%\Podstrochnik\log.txt` — запуск, запросы, ошибки. По нему разбираются проблемы.

## Модель

По умолчанию `deepseek/deepseek-v4.1-flash` через OpenRouter, без reasoning: быстро и дёшево,
картинки читает сама модель, отдельный OCR не нужен.

## Сборка

Нужен .NET SDK 8 (официальный от Microsoft) и команда:

```
dotnet publish -c Release -r win-x64
```

Интерфейс лежит в `ui/` и вшивается в exe; его можно открыть в браузере
(`ui/preview.html`) и посмотреть без сборки. Ключ в сборку вшивается файлом
`EmbeddedKey.g.cs` (шаблон — `EmbeddedKey.cs`); сборки с вшитым ключом не выкладываются.
